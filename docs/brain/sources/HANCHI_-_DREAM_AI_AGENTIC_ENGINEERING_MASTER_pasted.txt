4. HIGH-SIGNAL MEMORY VS CONTEXT_ROT

Two memory levels are required.

HIGH-SIGNAL

Normal retrieval.

Contains:

durable identity

stable communication preferences

current goals

important people

active projects

current decisions

recurring workflows

reusable knowledge

meaningful technical preferences

persistent constraints

important recurring habits

CONTEXT_ROT

Historical searchable archive.

Contains:

old daily events

historical client messages

old project states

one-off conversations

temporary plans

obsolete ideas

historical research

exact timestamps

non-essential personal information

older relationship/project history

other details that may matter in rare cases

CONTEXT_ROT is NOT deleted.

It is NOT normally injected into prompts.

It is searched only when:

the user explicitly asks about history

a specific date/time is requested

normal memory cannot answer

a project history is incomplete

identity is ambiguous

there is a contradiction

an older decision needs verification

the user says they remember telling the AI something before

When retrieved, label it:
[Historical Context]

Historical information must never silently override current high-signal information.
